                                      4 — Introduction to Tableau and Installation



AIM:
To install Tableau Desktop/Public and understand its interface.

ALGORITHM:
1. Start the computer.
2. Open a web browser.
3. Visit the official Tableau website.
4. Download Tableau Public or Tableau Desktop.
5. Install the downloaded application.
6. Open Tableau and explore its interface.
7. Identify worksheets, dashboards, and stories.
8. Stop.

PROCEDURE:
1. Open the official Tableau website.
2. Download Tableau Public or Tableau Desktop.
3. Run the installer and complete the installation.
4. Launch Tableau.
5. Explore the start page and workspace.
6. Identify the worksheet, dashboard, and story options.
7. Observe the available data visualization features.


Sample Output:

Tableau is installed and opened successfully.

The following components are identified:
1. Worksheets
2. Dashboards
3. Stories
4. Data connection options
5. Visualization workspace

Result:
Tableau was installed and its interface was studied successfully.
